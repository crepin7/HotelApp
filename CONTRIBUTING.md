# Contributing to HotelApp

Thank you for considering contributing to HotelApp! We welcome contributions from the community.

## How to Contribute

1. Fork the repository on GitHub
2. Clone your fork locally
3. Create a new branch for your feature or bug fix
4. Make your changes
5. Ensure your code follows the project's coding standards
6. Add tests if applicable
7. Commit your changes
8. Push to your fork
9. Submit a pull request

## Coding Standards

- Follow the Java Code Conventions (https://www.oracle.com/java/technologies/javase/codeconventions-contents.html)
- Use meaningful variable and method names
- Write Javadoc for public classes and methods
- Keep methods small and focused
- Handle exceptions appropriately
- Do not commit credentials or sensitive information

## Pull Request Process

1. Ensure your pull request description clearly describes the problem and solution.
2. The pull request must be reviewed by at least one maintainer.
3. Once approved, maintainers will merge the pull request.
4. Please keep your fork updated with the upstream repository.

## Reporting Issues

Please use the GitHub issue tracker to report bugs or request features. When reporting a bug, include:
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Any relevant screenshots or logs
